# Колія

Веб-калькулятор для сівби: рахує, **які висівні секції глушити на сівалці й на
якому проході**, щоб на полі лишилися смуги під колеса обприскувача.

Колію нарізають під час сівби — частину секцій вимикають, і по незасіяних
смугах потім ходить обприскувач та розкидач, не толочачи посів. Порахувати це
усно важко: результат залежить від захвату обох машин, міжряддя, колії та
ширини шини, а помилка на одну секцію тягнеться через усе поле й повторюється
на кожному циклі.

Живе тут: **https://tramline-calc.onrender.com**

## Вкладки

**Розрахунок** — головне. Працює без входу: людина в полі має отримати число,
а не форму реєстрації.

**Мої поля** і **Техніка** — збережені набори. Господарство роками має ті самі
два-три комплекти й десяток полів; вводити їх щоразу заново безглуздо. Тут
потрібен акаунт — інакше нема де зберігати.

**Довідник** — таблиця «захват сівалки × захват обприскувача», як у посібнику
до машини. Рахується тією ж функцією, що й головна відповідь, тож розійтися
вони не можуть. Ваша комбінація підсвічена, навіть якщо її немає в
стандартному ряду.

## Запуск

Потрібні Node.js 18+ і Postgres.

```bash
npm install
cp .env.example .env    # DATABASE_URL і JWT_SECRET
npm run build
npm start               # http://localhost:3002 — API і сторінка разом
```

```bash
npm run dev             # Vite на 5180, коли працюєш над фронтендом
npm run server          # API окремо
npm test                # 35 тестів на розрахунок, вбудований ранер Node
```

Розрахунок цілком у браузері — сервер до нього не причетний і потрібен лише
для акаунтів. Останні введені дані лишаються в `localStorage`, тож і без входу
програма памʼятає, з чим ви працювали.

Схема бази створюється сама при старті (`server/db.js`); усі міграції
додавальні та ідемпотентні, тож той самий код обслуговує і порожню базу, і ту,
що вже має живі акаунти.

## Що рахує

**Головне — що сказати механізаторові.** Відповідь стоїть угорі сторінки одним
реченням: «на 2-му проході з 3 вимкнути секції 5 і 8». Поруч — **ритм**, число
проходів до повтору візерунка: саме його вводять у термінал сівалки (Amazone,
Lemken, Horsch питають це число). Решта — доказова база до них.

**Підбір колії.** Сказати «колесо стало на рядок» — половина роботи. Колію на
більшості обприскувачів пересувають за пів години ключем, тож програма показує
значення, за яких глушити не доведеться нічого. На соняшнику різниця між 2,1 і
2,8 м колії — це кілька центнерів з поля.

**Розворотні смуги.** Обсів по периметру сіють окремо й по ньому розвертаються,
тож колія в ньому не потрібна. Він змінює робочу площу, кількість колій і те,
де ляже перша з них.

**Розкидач.** Якщо по тих же коліях ходить розкидач добрив, його захват має
бути кратним обприскувачу — інакше він потрапляє в колію не щоразу, а решту
часу їде по посіву. Програма перевіряє й показує, що поміняти.

**Гроші.** Колія — це свідомо недосіяна площа. Питання не в тому, скільки вона
з'їдає, а в тому, чи менше, ніж витоптування без неї. Обидві цифри рахуються з
одних даних і обидві видно, щоб можна було посперечатися з розрахунком.

## Як влаштована математика

Поле розглядається в розрізі поперек руху. Сівалка кладе проходи завширшки
`W = секції × міжряддя`, обприскувач — `S = k · W`. Колеса в проході `j`
стоять на `(j + 0.5)·S ± T/2`, де `T` — колія. Смуга під колесом —
`± (шина/2 + запас)`. Секція глушиться, якщо її рядок потрапляє в цю смугу.

Звідси все інше, без окремих випадків:

- **Відношення захватів має зводитися до дробу з малим знаменником.** Ціле —
  звичайний ритм. Половина (4,5 · 5,5) — **асиметричний**: на одному проході
  глушать один бік, на іншому другий, і візерунок повторюється не через
  чотири проходи, а через девʼять. Так робить сівалка 4 м під обприскувач
  18 м — серійні машини це вміють, тож відмовляти в такій комбінації не можна.
  Коли ж не зводиться зовсім — програма скаже й підкаже, що поміняти.
- **Непарний `k`** (3, 5, 7…) — центр обприскувача збігається з центром
  проходу сівалки, уся колія лягає в один прохід, симетрично.
- **Парний `k`** (2, 4, 6…) — центр припадає на стик проходів, і колія
  розривається: по половині на двох сусідніх проходах. Половинний перший
  прохід зсуває сітку сівалки на `W/2` і збирає колію в один прохід.
- **Широке міжряддя.** При 70 см колесо часто вкладається між рядками — тоді
  вимикати не треба нічого. Але це гостро чутливо до колії: при 70 см рядках
  **2,8 м ведуть колесо міжряддям, а 2,1 м — точно по рядку**. Обидва випадки
  покриті тестами.

## Дві схеми

**Поле згори** — колії по всій ширині, сітка проходів обприскувача, обсів по
периметру. Поле майже ніколи не ділиться націло, тому останній прохід виходить
неповним — програма показує це окремо, бо саме на краю колія лягає не туди, де
її чекають. Дуже витягнуте поле стискається по довжині (уздовж неї нічого не
змінюється), і схема про це прямо каже.

**Прохід зблизька** — один цикл з кожним рядком: видно, які саме секції
глушаться й де проходить колесо.

## Припущення

Сівалка й обприскувач заходять у поле з одного краю; секції рахуються зліва
направо за напрямком руху. Розрахунок одновимірний — рельєф, клини й нерівні
межі поля не враховуються.
