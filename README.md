# Технологічна колія

Веб-калькулятор для сівби: рахує, **які висівні секції вимкнути на сівалці й на
якому проході**, щоб на полі лишилися смуги під колеса обприскувача.

Колію нарізають під час сівби — частину секцій глушать, і по незасіяних смугах
потім ходить обприскувач та розкидач, не толочачи посів. Порахувати це усно
важко: результат залежить від захвату обох машин, міжряддя, колії та ширини шини,
а помилка на одну секцію коштує врожаю на кожному проході через усе поле.

## Запуск

Потрібен Node.js 18+.

```bash
npm install
npm run dev      # http://localhost:5180
```

```bash
npm run build    # статична збірка в dist/ — кладеться на будь-який хостинг
npm run preview  # подивитися зібране
npm test         # 16 тестів на розрахунок, вбудований ранер Node
```

Бекенда немає: усе рахується в браузері, останні введені дані лишаються в
`localStorage`. `dist/` можна просто скопіювати на сервер або відкрити з флешки.

## Що вводимо

| Поле | Що це |
|---|---|
| Культура | пресет міжряддя й кількості секцій (соняшник, кукурудза, пшениця…) |
| Секцій на сівалці | скільки висівних секцій / сошників |
| Міжряддя | м, для соняшнику зазвичай 0,7 |
| Захват обприскувача | м, ширина штанги |
| Колія | м, відстань між центрами коліс обприскувача |
| Шина | м, ширина протектора |
| Запас з кожного боку | м, на знос кермування — типово 0,1 |
| Половинний перший прохід | лікує парний коефіцієнт (див. нижче) |
| Ширина й довжина поля | м — з них будується схема всього поля й площа |

## Як це рахується

Поле розглядається в розрізі поперек руху. Сівалка й обприскувач заходять з
одного краю: сівалка кладе проходи завширшки `W = секції × міжряддя`,
обприскувач — `S = k · W`. Колеса в проході `j` стоять на `(j + 0.5)·S ± T/2`,
де `T` — колія. Смуга під колесом — `± (шина/2 + запас)`. Секція глушиться,
якщо її рядок потрапляє в цю смугу.

Звідси все інше, без окремих випадків:

- **`k` має бути цілим.** Інакше колеса щоразу падатимуть у нове місце —
  програма це скаже й підкаже, який захват обприскувача або яка сівалка підійде.
- **Непарний `k`** (3, 5, 7…) — центр обприскувача збігається з центром проходу
  сівалки, уся колія лягає в один прохід, симетрично.
- **Парний `k`** (2, 4, 6…) — центр припадає на стик проходів, і колія
  розривається: по половині на двох сусідніх проходах. Вмикання половинного
  першого проходу зсуває сітку сівалки на `W/2` і збирає колію в один прохід.
- **Широке міжряддя.** При 70 см колесо часто вкладається між рядками — тоді
  вимикати не треба нічого, і програма показує, скільки лишилося до рядка.
  Але це чутливо до колії: при 70 см рядках **2,8 м колії ведуть колесо
  міжряддям, а 2,1 м — точно по рядку**. Обидва випадки покриті тестами.

## Дві схеми

**Усе поле** — вигляд згори в справжніх пропорціях: усі колії по ширині, сітка
проходів обприскувача, кількість колій, їхня довжина в кілометрах і скільки
гектарів під ними. Поле майже ніколи не ділиться націло, тому останній прохід
обприскувача виходить неповним — програма це показує окремо, бо саме на краю
поля колія лягає не туди, де її чекають. Дуже витягнуте поле стискається по
довжині (уздовж неї нічого не змінюється), і схема про це прямо каже.

**Схема проходу** — один цикл зблизька, з кожним рядком: видно, які саме секції
глушаться й де проходить колесо.

## Структура

```
src/
├── lib/tramline.js    увесь розрахунок, без React — його й покривають тести
├── lib/format.js      стиснення діапазонів (4,5,6 → 4–6) і числа по-українськи
├── lib/presets.js     довідники культур, захватів, ходових
├── components/FieldPlan.jsx     схема всього поля
├── components/FieldDiagram.jsx  схема одного проходу зблизька
├── components/PassPlan.jsx      план проходів для кабіни
└── App.jsx            форма й показники
test/tramline.test.js  16 тестів: парність, половинний прохід, міжряддя,
                       підказки, розкладка поля, неповні проходи, площі
```

## Припущення

Сівалка й обприскувач заходять у поле з одного краю; секції рахуються зліва
направо за напрямком руху. Розрахунок одновимірний — рельєф, клини й розворотні
смуги не враховуються.
